One genuine one-line story about a small good thing that happened today,
written for the
[make.fun](https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d)
bounty "Make the Judge Smile".

> My grandmother called today just to say the plums she mailed should be ripe by now, then stayed on the line so we could eat one together, both of us slurping, until she said 'Good' and hung up.

## How it works

`main.ts` (Node 22, standard library only) writes the line to the output
directory, byte for byte — `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`.
Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The output `entry.txt` is a single line, 1–200 characters, and identical on
every run.
